# 결과 개인화

결과 공유 코드는 기존 계약대로 문항 세트와 9유형 합산 점수만 담는다. 원 응답은 URL이나 서버로 보내지 않는다.

- 모든 방문자: 상위 1·2·3위 비교, 점수 차이, 1위 유형이 맞지 않을 수 있는 신호
- 검사를 완료한 브라우저: `sessionStorage`에 결과 코드별 원 응답을 보관해 응답 근거를 표시
- 90문항 본인 결과: 동기·두려움·주의 초점·관계·부하의 다섯 세부 경향
- 27문항 본인 결과: 상위 두 유형에서 아직 답하지 않은 문항을 3개씩 골라 보조 비교

추가 질문은 기존 결과나 공유 코드를 변경하지 않는다. 유형을 확정하는 재검사가 아니라 두 후보를 구분해 읽기 위한 보조 정보다. 공유 링크를 다른 브라우저에서 열면 원 응답과 추가 질문 상태는 노출되지 않는다.
