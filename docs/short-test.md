# 27문항 단축 검사

- 기본 경로: 유형당 3문항, 총 27문항. 원점수는 유형별 3~15점이다.
- 문항은 기존 90개에서 선택하고, 유형마다 세 가지 서로 다른 측면과 역채점 한 문항을 포함한다.
- 결과의 1·2위 점수 차이가 2점 미만이면 추가 질문이 필요하다는 안내를 노출한다.
  이는 제품상의 탐색 기준이며, 검증된 신뢰도나 확률 기준이 아니다.
- 추가 응답은 강제하지 않는다. 본인이 만든 27문항 결과 하단에서 남은 63문항으로
  이어가 총 90문항을 완료한다. 기존 27개 답변은 다시 묻지 않는다.
- 결과가 애매하지 않아도 같은 확장 경로를 제공한다. 90문항은 더 다양한 상황을
  살펴보지만 정확도 향상이나 유형 확정을 보장하지 않는다.
- 새 공유 코드는 버전 3이다. 기존 버전 2의 45문항 결과와 버전 1의 90문항 결과는
  해당 척도를 유지해 표시한다.
- 진행 계획이 바뀌어 기존 저장 진행본은 새 서명과 맞지 않으면 복원하지 않는다.
  기존 공유 링크 자체는 그대로 열 수 있다.
- 결과 소유자 판별 방식은 이번 변경 범위에서 제외한다.

## 이후 검증

실제 응답에 대한 단축판의 타당성 검증은 아직 없다. 27/90문항을 모두 완료한 응답에서
유형 순위 변화와 애매한 결과 비율을 비교해야 한다. 이 변경에는 응답 수집이나 추적 기능을
추가하지 않았다.
